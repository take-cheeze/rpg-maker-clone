- The bc2cpp arm pruning graph (`codegen_arm_prune.rb`) now takes its normal and catch-handler edges from the bytecode IR (`Program#forward_reachable`, `successor_lists`, `raise_targets`) instead of re-deriving them per opcode. It keeps only the decided-branch refinement and ENTER's edges locally. `RETNIL`, `RETSELF`, `RETTRUE`, `RETFALSE` and `BREAK` no longer fall through, so instructions reached only past them count as unreachable. The generated C++ changes only by dropping three dead `goto`s after a `return`.
