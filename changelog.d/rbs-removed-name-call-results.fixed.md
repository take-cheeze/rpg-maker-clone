- **Type check** no longer takes a body-inferred return class from a call of a method name the program may undefine or remove. The removal refusal that already applied to an implicit self-call's declared contract now also applies to the inferred call result of every send of that name, with an explicit receiver or an implicit self: the result is untyped. A removal in any class counts, and a computed name refuses every name. Covered by `scripts/bc2cpp/self_call_override_contracts_check.rb` (section g).
