- **Type check** no longer gives an implicit `self` call the owner's return contract alone. The call dispatches on the receiver's class, so its declared result now joins the contracts of every class the closed world bounds under the owner: with `Child < Base` overriding `greet`, `Base#via_self` is `Symbol | Integer`, not `Symbol`. A call with no override keeps the owner's contract. The call is left untyped when the receiver set is open (a subclass from outside the program, a module with no bounded includers, a core ancestor such as `Object`), when a receiver runs `method_missing`, or when a receiver's chain is unknown. Covered by `scripts/bc2cpp/self_call_override_contracts_check.rb`.
