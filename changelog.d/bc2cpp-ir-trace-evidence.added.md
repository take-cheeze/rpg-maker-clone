- **bc2cpp** `scripts/bc2cpp/type_check.rb --trace CANDIDATES.rbs` takes the trace candidates from `scripts/bc2cpp/trace_types.rb candidates` as runtime evidence. A `possible_mismatch` return whose method the trace observed only inside its RBS contract is reported as an info note (`TC1009`) instead of a warning (`TC1008`), marked `provenance: trace`. Its status stays `possible_mismatch`, and `mismatch` rows are never changed. Checked by `scripts/bc2cpp/ir_trace_evidence_check.rb`.
