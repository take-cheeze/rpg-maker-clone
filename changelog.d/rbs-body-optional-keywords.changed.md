- **Type analysis** now types optional keywords from their call sites. The candidate RBS and the type-check report write `?k: T`, and the method body reads the joined type when every call passes the key or omits it. An omitting call binds the default, so the default's class joins the passed values, and a non-literal default keeps the keyword `untyped`. A `**splat` caller or an unknown caller also keeps it `untyped`. Covered by `scripts/bc2cpp/ir_argument_types_check.rb`.
