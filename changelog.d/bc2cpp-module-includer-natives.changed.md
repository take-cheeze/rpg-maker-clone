- **Type check** types an implicit `self` call in a module method from the module's includers when a native source only defines or looks up the module's name (`mrb_define_module`, `module_function`), instead of refusing every module that a native source spells. A native include by a computed name, a computed dispatch name, a `include` method override, or a constant alias of the module still keeps the call untyped; a foreign Ruby source that spells the module still does. A send whose name a program source defines on an includer is untyped. Covered by `scripts/bc2cpp/module_includer_bound_check.rb`.
