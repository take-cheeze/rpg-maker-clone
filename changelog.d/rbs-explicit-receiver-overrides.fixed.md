- **Type check** no longer gives an explicit-receiver call the owner's return contract alone. A call such as `o.greet` on a receiver declared `Base` may dispatch to a program subclass that overrides `greet`, so its declared result now joins the contracts of every subclass the closed world bounds, as implicit self-calls already did. With `Child < Base` overriding `greet` to return `Integer`, the call is `Symbol | Integer`, not `Symbol`. A call with no override keeps its contract. The call is left untyped when the receiver set is open, including when there is no closed world. Declared core receivers such as `Array` are now also untyped, a conservative precision loss. Covered by `scripts/bc2cpp/explicit_receiver_override_contracts_check.rb`.
