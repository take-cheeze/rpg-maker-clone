- **Trace evidence** compares block parameters. A `BC2CPP_TRACE_TYPES` dump names the one method that yields to each block body (`BLOCK_YIELD` rows, from `tools/bc2cpp/block_yielders.rb`), and `scripts/bc2cpp/rbs_suggestion_trace_check.rb` checks the yielded values against the `{ (T) -> U }` block the candidate declares for that method. A body with several possible yielders, an escaping block, a `&blk` parameter or dynamic dispatch is counted as undecided, never a contradiction. Dumps without the rows still parse. See `docs/bc2cpp-ir-feedback.md`.
