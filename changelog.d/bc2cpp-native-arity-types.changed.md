- **bc2cpp** gives a native method the parameter list its registration's aspec declares when its C body does not read its arguments through `mrb_get_args`: `MRB_ARGS_NONE()` is `()`, and `MRB_ARGS_REQ` and `MRB_ARGS_OPT` give required and optional parameters. A rest, post-required or keyword aspec keeps the rest parameter. mruby checks the same arity before the call, so a call with the wrong count is reported at compile time.
