- **Non-SDL backends now bind the RPG2003 Numbers/Operators keys** (`RGSS::Input::N0`..`PERIOD`). The terminal/sixel backends type them from a real keyboard (`mruby-rgss/src/terminal.cxx`); the PSP backend binds `N0`–`N4` to its spare Square/L/R/Start/Select buttons (its pad bitmask widened to `uint64_t`, since ids 21–35 no longer fit 32 bits); the Wio Terminal still leaves them unbound (no free pin). Input Number and the numeric/operator Key Input Processing groups work off-SDL where hardware permits.
