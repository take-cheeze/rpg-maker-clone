- **bc2cpp** escape analysis no longer treats an Array literal receiver of a block-taking send with a literal block (`[1, 2].each { }`, `.map { }`) as escaping. `Array#each` and the Enumerable bodies that return `to_enum` without a block are judged with the block given, so the no-block arm is not walked; a send without a literal block (`each` with no block, `each(&blk)`) keeps its verdict. Covered by `scripts/bc2cpp/array_literal_block_check.rb` (verdicts for the confined and still-escaping shapes, and compiled-against-interpreted parity).
