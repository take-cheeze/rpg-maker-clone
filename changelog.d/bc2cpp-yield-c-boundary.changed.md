- **bc2cpp** yield analysis no longer counts a native's callback into Ruby as a Fiber yield path: mruby raises `FiberError` across that C-boundary frame, so the original program never suspends through it. A computed send on `self` now reaches only methods of self's class chain. See [`docs/bc2cpp-yield-c-boundary.md`](docs/bc2cpp-yield-c-boundary.md); `BC2CPP_YIELD_C_BOUNDARY=0` and `BC2CPP_YIELD_SPELLED_SENDS=0` restore the old rules.
