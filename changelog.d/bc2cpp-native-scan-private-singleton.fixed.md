- **bc2cpp** now also recognises native registrations made with `mrb_define_private_method[_id]` and `mrb_define_singleton_method[_id]`, including an `mrb_state` class field as the owner. Kernel's private `exit`, `exit!`, `proc` and `lambda` (and `binding`) were seen as unregistered, so a Ruby `def exit` on a user class could be devirtualised over the native method for an `Array` receiver.
