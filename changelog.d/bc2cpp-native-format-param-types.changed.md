- **bc2cpp** types the parameters of native methods from their `mrb_get_args` format string. A class type is declared where mruby checks the argument (`S`, `z`, `A`, `H`, ...). The numeric and symbol letters (`i`, `f`, `n`) are checked too, as `Numeric` and `Symbol | String`, since mruby accepts only those classes and raises `TypeError` otherwise. A call with the wrong argument count or class is reported at compile time instead of at run time.
