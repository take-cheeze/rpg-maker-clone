- bc2cpp: a callee whose nested block outlives the call and captures the method's block (`def mk(&b); Enumerator.new { |y| y << b.call }; end`, `Hash.new { |h, k| b.call(k) }`) no longer receives a frame-local block; the caller's block was freed with its frame while the Enumerator or Hash still read it (heap-use-after-free under `BC2CPP_STACK_BLOCK_MALLOC` + ASan, a crash in `Enumerator.produce(...).next`).
