- **bc2cpp register flow** now also optimizes methods with a `begin`/`rescue` region: the pass models the exception path from each protected instruction to its handler, so dead register copies and constant loads are removed and plain copies propagated there too. Generated C++ shrinks for those methods; `BC2CPP_REGISTER_FLOW_HANDLERS=0` restores the previous refusal, and `BC2CPP_REGISTER_FLOW=0` still turns the whole pass off.
