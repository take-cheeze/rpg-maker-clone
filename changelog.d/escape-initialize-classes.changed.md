- **bc2cpp escape analysis** no longer refuses every `new` because an interpreted mrblib defines `initialize`. A hidden `def` in a class body is relevant only to receivers whose ancestry includes that class, and anything that cannot be attributed keeps its name-level refusal. Zero-argument `new` sites are analysed too. These verdicts feed the block-fallback proof, so a block passed to a name that only hidden classes define can now be proven where it was refused before. See `docs/bc2cpp-foreign-method-scanning.md`.
