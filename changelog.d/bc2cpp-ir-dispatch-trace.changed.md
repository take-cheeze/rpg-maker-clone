- **bc2cpp** dispatch-target traces now answer from the bytecode IR per path (ADR 0508). A constant assigned a Hash on one path and an Array on the other is no longer a container constant, a `when` literal is only a literal when every path loads it, and a `.new` or GETIDX alias is traced through joins only when it dominates the read. Join mode is passed to each trace rather than held in a global, so a nested unguarded trace is no longer answered join-blind. Covered by `scripts/bc2cpp/dispatch_ir_trace_check.rb`.
