- **bc2cpp**: a signature's `*T` rest parameter now types the body's element reads (`items[i]`) as `T`, where the call-site join is absent or withheld (a rest array that is mutated, captured by a closure, packed by a zero-argument `super`, or reachable by `binding`/`eval`). The join still wins when both exist, as for a required parameter. Only a positional-only rest declares it. The `*T` is a body fact only, so the report has no row for it; it no longer gets the TC1005 "no hint" note. Checks: `scripts/bc2cpp/ir_argument_types_check.rb`.
