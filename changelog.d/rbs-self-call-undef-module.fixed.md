- **Type check** no longer gives an implicit `self` call a return contract when the program may remove the called method. A name that some class undefines or removes (`undef_method`, `remove_method`, the `undef` keyword, or the same through `send`, or with a name that is not a literal) has no self-call contract, so the call stays untyped. A call inside a module now joins the contracts of its includers (`M#via_mod` with `A` and `B` including `M` is `Symbol | Integer`), and stays untyped when the program may hold an includer it cannot place (an `include` with computed modules, a runtime `extend`, a native or outside source naming the module) or a receiver is `prepend`ed. Covered by `scripts/bc2cpp/self_call_override_contracts_check.rb`.
