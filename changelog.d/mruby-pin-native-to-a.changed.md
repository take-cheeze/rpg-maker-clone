mruby: a fork pin bump with four changes. `Enumerable#entries`, `#to_a`, and `#inject` (with `reduce`) are native cfuncs, so their blocks no longer run as bytecode once per element. `Class#new` allocates directly when `allocate` is the built-in one (a user-defined `allocate` is still sent by name). `Hash#merge` without a block runs natively (the block form stays in Ruby). Behavior matches the Ruby versions it replaces, with one exception: `Method#arity` for `to_a`, `entries`, `inject`, and `reduce` reports -1 (it was 0 or 1), because a cfunc does not record an arity yet.
