- Auto-start (Autorun) events now re-trigger every frame the way real RPG_RT does, once the previous lap finishes. `Scene::Map#update` clears `@started_auto` / `@started_common` each frame so an eligible Autorun whose page condition still holds re-fires from its first line on every subsequent frame (the classic "spams every frame" case), instead of running at most once per map visit. A guarded auto-start still fires at most once per visit via `@auto_once` / `@auto_once_common`, so a guarded event does not re-fire and the gate does not trigger an event-page rebuild that would wipe an unrelated event's in-flight forced route. ~26 `scripts/rpg2k_scene_check.rb` auto-start fixtures that issue one-shot commands were re-baselined to guard themselves (via `one_shot_auto` / `player_route_page` / `inn_scene`'s `guard:` flag), standing in for the page-condition gate a real game would use: the flag is a check-harness one, read off the page by `Scene::Map#page_guarded` once per page rebuild rather than per frame, so an auto-start on real game data — where no page carries it — is never guarded and gates itself through its own page conditions. The within-frame same-event restart (a no-wait Common Autorun consuming the frame's step budget) remains open.
