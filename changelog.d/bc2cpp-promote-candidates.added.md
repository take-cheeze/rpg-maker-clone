- **bc2cpp** gains `scripts/bc2cpp/promote_candidates.rb`, a reviewed step that copies accepted candidate RBS into `sig/bc2cpp/declarations.rbs`. It is a dry run by default (a diff and the skipped members, nothing written), `--write` applies it, and the result is parsed with RBS. It adds only absent members, skips `untyped` and undeclared types, and never writes the base section. Covered by `scripts/bc2cpp/promote_candidates_check.rb`; see `docs/bc2cpp-promote-candidates.md`.
