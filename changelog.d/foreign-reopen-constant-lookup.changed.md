- The bc2cpp constant lookup no longer refuses a core class that a foreign Ruby source reopens at top level (`class Array`), defines a top-level exception class (`NameError`) under its superclass, or binds `RGSS` through a `mrb_const_set` lookup argument. Module owners search their includes and then Object. `RGSS` and `LCF` now resolve from the closed world. Generated code is unchanged apart from the constants these now resolve.
