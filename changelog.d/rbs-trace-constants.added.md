- **bc2cpp** `BC2CPP_TRACE_TYPES=1` now records the value of each constant read (GETCONST, GETMCNST), one `CONST_SITE` row per read named by the `Owner::NAME` the closed-world lexical analysis resolved it to (`-` when unproven) and its `CONST_CLASS` classes. `scripts/bc2cpp/rbs_suggestion_trace_check.rb` compares a resolved read with the `NAME: T` the candidate declares in that scope. An unresolved read, an undeclared constant and an overflowed read are counted, never failed. Dumps without the new rows still parse. Documented in `docs/bc2cpp-ir-feedback.md`; checked by `scripts/bc2cpp/param_trace_return_check.rb`, `scripts/bc2cpp/lexical_const_check.rb` (with `MRBC`) and the gate self-test.
