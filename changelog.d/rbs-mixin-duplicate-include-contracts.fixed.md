- **Type check** no longer takes a method's return contract from a module that a class reaches through two include paths (for example `Base` and `Child < Base` both including `M`). CRuby keeps that module at its first insertion, so the call dispatches to the superclass method, and the check now refuses the call instead of reporting the module's contract. Mixin lookup for a single include path, prepend and nested includes is unchanged. Covered by `scripts/bc2cpp/rbs_mixin_contracts_check.rb`.
