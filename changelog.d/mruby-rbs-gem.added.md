- The RBS parser is available to mruby builds as the `mruby-rbs` gem. Its C core comes from the `take-cheeze/rbs` fork (`3rd/rbs`, a submodule). `RBS::Native.parse_signature` returns the binary serialization that `RBS::WASM::Deserializer` decodes into `RBS::AST` objects. The Ruby library is built into one mrblib from a fixed file list; the mruby deviations are listed in `mruby-rbs/tools/build_mrblib.rb`.
