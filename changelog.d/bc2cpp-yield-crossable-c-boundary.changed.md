- **bc2cpp** Fiber crossability now follows the yield analysis's C-boundary and spelled-send rules: a native call inside a Fiber no longer makes every method a native may call back (an `initialize` run by `Class#new`) crossable, and a computed send reaches only the spelled names (self's chain for a send on `self`). Optcarrot's `CPU#initialize` and `PPU#initialize` compile, so both classes get their embedded ivar layout: 180 frames take 3.73 s compiled against 12.79 s interpreted and 4.53 s on CRuby. `BC2CPP_YIELD_C_BOUNDARY=0` / `BC2CPP_YIELD_SPELLED_SENDS=0` restore the old edges.
