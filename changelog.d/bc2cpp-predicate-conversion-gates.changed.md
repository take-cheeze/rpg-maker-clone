- **bc2cpp** enforces two rules on Ruby sources at build time. A method whose name ends in `?` must return `bool`, which the compiler proves from the source; a predicate it cannot prove fails the build unless it is listed in `scripts/bc2cpp/predicate_whitelist.txt`. `to_s`, `to_str`, `to_int`, `to_ary` and `to_hash` may take only optional positional parameters, and their returns are runtime-checked: a value of the wrong class raises `BC2cppHintViolation`. See ADR 0487.
